# Mini Archive View

[![SwiftUI](https://img.shields.io/badge/SwiftUI-5.0-blue.svg)](https://developer.apple.com/xcode/swiftui/)
[![Platform](https://img.shields.io/badge/Platform-iOS-lightgrey.svg)](https://developer.apple.com/ios/)

## Features

- **3D Book Animation** - Realistic page-turning effect with rotation3DEffect
- **Interactive Stamp Collection** - Tap stamps to view them full-screen
- **Smooth Transitions** - Matched Geometry Effect for seamless animations
- **Customizable Themes** - Change the book cover color dynamically
- **Staggered Layout** - Stamps fan out when closed, overlap when open
- **Responsive Design** - Works on multiple Apple platforms
